When models age: misleading drift alerts.

Can statistical monitoring methods tell apart data changes that really hurt model performance from changes that only set off misleading drift alerts?

Course project for Statistical Learning & Multivariate Analysis, UC San Diego.

RLassoPCADrift detectionIn progress

The problem

Detecting that data have changed is not the same as showing that a model has become less accurate. Alerts that fire without a real drop in performance waste time and erode trust in monitoring.

The data

The UCI Gas Sensor Array Drift dataset: 13,910 measurements from 16 metal-oxide sensors (128 features) across 6 gases, collected in 10 batches over about 36 months.

Methods

A chronological design trains on early batches, validates on middle batches, and locks the final batches until every choice is frozen. Preprocessing is fit on training rows only. Models include lasso multinomial logistic regression and k-nearest neighbors, with principal component analysis (PCA) to explore structure. Drift is measured with Kolmogorov-Smirnov tests (Benjamini-Hochberg correction) and a domain-classifier area under the curve (AUC).

FOR THE TECHNICAL READER

Known data issues are documented up front: the gas mix changes between batches, toluene is missing from three batches, batches are unevenly spaced in time, and concentration shifts confound sensor aging.

Next steps
