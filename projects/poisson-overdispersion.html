When Poisson lies: inference for overdispersed counts.

When count data are more variable than a Poisson model assumes, which approach still gives valid inference?

Group project for the Biostatistics Practicum, UC San Diego, with Flossie Zhang, Yiyi Zhu, and Yinan Zhu.

The problem

Counts such as hospital visits are often overdispersed: most people have few, and a few have many. Fitting a Poisson model to such data can make uncertainty look far smaller than it is.

The data

Simulated data: 1,000 datasets at each sample size (n = 200 and n = 1,000), with counts drawn from a negative binomial distribution with dispersion 3, so the variance far exceeds the mean.

Methods

The same datasets were analyzed with Poisson regression, negative binomial regression, and Poisson regression with robust (sandwich) standard errors. Each model was judged on bias, the ratio of claimed to actual variance, and the type I error of a Wald test of the true slope.

Findings

All three models estimated the slope without meaningful bias but differed in how honestly they reported uncertainty. Poisson inference was invalid at both sample sizes (type I error 0.84 to 0.88), because more data does not fix a wrong variance formula. The negative binomial model held type I error near 0.05 and was the most efficient. Sandwich standard errors improved with sample size (0.18 to 0.12) but needed large samples with heavy-tailed counts.

FOR THE TECHNICAL READER

Claimed-to-actual variance ratios were 0.007 to 0.010 for Poisson, near 1 for the negative binomial, and 0.68 to 0.81 for the sandwich estimator. With 1,000 replicates, a true 5% rate falls between about 0.036 and 0.064 from Monte Carlo error alone.
