Multi-nucleotide mutations in SARS-CoV-2.

Do mutations on the same branch of the SARS-CoV-2 phylogeny sit closer together than chance, as multi-nucleotide mutations would predict?

Undergraduate research in the Russ Corbett-Detig Lab, UC Santa Cruz.

The problem

Most mutation models assume point mutations happen independently. Multi-nucleotide mutations (MNMs) are two or more nearby substitutions created in a single event, for example by an error-prone polymerase. If they are common, models that ignore them miss real biology.

The data

A mutation-annotated tree from Ultrafast Sample placement on Existing tRees (UShER). The real test used 422 early-pandemic genomes, with 500 mutations placed on 283 branches by parsimony. A simulated tree of 12,140 branches with planted MNMs was used to validate the pipeline.

Methods

For each mutation on a branch with at least two mutations, the distance to the nearest other mutation on the same branch was computed. A permutation null shuffled which branch each mutation belongs to while keeping each branch's mutation count fixed, and a stricter null shuffled only within substitution type. Results are reported as observed-to-expected ratios with permutation p-values at several distance thresholds.

Findings

The pipeline recovered planted MNMs and stayed calibrated when none were present. On the real tree, same-branch mutations sat 5 to 10 times closer together than chance predicts (p = 0.001), and the excess held under the stricter null (4.6 to 7.3 times). A Kolmogorov-Smirnov test was not significant (p = 0.29), showing that the observed-to-expected counts detect an effect the test misses. The clearest case is a known MNM that changes three adjacent bases in the nucleocapsid gene.

FOR THE TECHNICAL READER

Sensitivity analyses masked the genome ends and restricted to internal branches to reduce sequencing artifacts. The original analysis treated the genome as circular; the rewrite treats the roughly 29.9 kb genome as linear.

Next steps

Add a null model that preserves each site's mutation frequency to separate hotspots from MNMs, run the full public tree, and model the MNM fraction by lineage and collection date.
